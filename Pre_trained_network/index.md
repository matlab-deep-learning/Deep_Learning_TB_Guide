Deep Learning Toolbox™ は、深層ニューラル ネットワークの構築、学習、および予測を容易にするための広範なツールと機能を提供します。特に、さまざまなタスク向けに**事前学習済みのネットワーク**が豊富に用意されており、これらのネットワークは新しいタスクの学習の出発点として活用できます。

### 事前学習済みネットワークの概要と特徴

Deep Learning Toolbox で提供される事前学習済みネットワークの多くは、**転移学習**や**特徴抽出**という手法で利用されます。
*   **転移学習**: 事前学習済みのネットワークを新しいタスクの学習の出発点として使用する一般的な手法です。ゼロからネットワークを学習させるよりもはるかに簡単で時間がかからず、少ない学習イメージで効率的に新しいタスクを学習させることができます。これは、事前学習済みのネットワークが既に多様な特徴を学習しており、それらの特徴が他の類似タスクにも適用可能であるためです。
*   **特徴抽出**: 事前学習済みのネットワークから学習済みの特徴を抽出し、それらの特徴を使用してサポート ベクター マシン (SVM) などの分類器に学習させる方法です。転移学習よりも短時間で深層学習を利用でき、GPU がない場合でも有効な開始点となります。

ほとんどの事前学習済みのイメージ分類ニューラル ネットワークは、ImageNet データベース のサブセットで学習されています。このデータベースには100万個を超えるイメージが含まれており、キーボード、マグカップ、鉛筆、多くの動物など、1000個のオブジェクト カテゴリに分類できます。

ネットワークの選択においては、**精度、速度、およびサイズ**が重要な特性となります。通常、これらの特性の間にはトレードオフが存在します。

*   **GoogLeNet** や **SqueezeNet** は高速なネットワークであり、データの前処理手順や学習オプションなど、さまざまな設定を試す際の迅速な反復に適しています。
*   初期設定が適切に機能することを確認した後、より正確な **Inception-v3** や **ResNet** などのネットワークを試して、結果が改善されるかを確認することが推奨されます。

Deep Learning Toolbox の最新のワークフローでは、`dlnetwork` オブジェクトの使用が推奨されています。`dlnetwork` オブジェクトは、より広範なネットワーク アーキテクチャをサポートし、ネットワークの構築、予測、組み込み学習、圧縮、Simulink®、コード生成、カスタム学習ループなど、さまざまな機能に対応する統一されたデータ型を提供します。

#### Deep Learning Toolboxにおける事前学習済みネットワークの種類

Deep Learning Toolbox は、画像分類だけでなく、オーディオ処理やオブジェクト検出など、さまざまなアプリケーション向けの事前学習済みネットワークを提供しています。

**1. イメージ分類用事前学習済みネットワーク**
これらのネットワークは主にImageNetデータベースで学習されており、物体認識に使用されます。

*   **SqueezeNet**:
    *   **特徴**: 非常に高速で軽量。転移学習の出発点として推奨されます。R2020a以降はサポート パッケージなしで利用可能です。
*   **GoogLeNet**:
    *   **特徴**: 高速で比較的小さなネットワーク。物体分類によく使用され、Webカメラからのリアルタイム分類 やDeep Dreamイメージの生成 にも利用されます。
    *   **Places365で学習させたGoogLeNet**: ImageNetの代わりにPlaces365データセットで学習されており、365種類のシーンカテゴリにイメージを分類できます。シーン分類のタスクで精度が向上する場合があります。
*   **Inception-v3**:
    *   **特徴**: より深いネットワークで、GoogLeNetよりも高い精度が期待できます。画像キャプション生成など、複雑なタスクにも使用されます。
*   **DenseNet-201**:
    *   **特徴**: 非常に深いネットワークで、高い精度を達成できます。R2021bではCPUでの推論性能が向上しています。
*   **MobileNet-v2**:
    *   **特徴**: メモリ使用量が少なく、モバイルデバイスやリソースが限られた環境での利用に適した効率的なネットワークです。
*   **ResNet-18, ResNet-50, ResNet-101**:
    *   **特徴**: Residual connections（残差接続）を使用することで、非常に深いネットワークの学習を安定させ、高い精度を実現します。ResNet-18は効率的で、リソースが限られた用途にも適しています。ResNet-50は複数ラベル分類にも使用されます。
*   **Xception**:
    *   **特徴**: Depthwise Separable Convolutionsを使用し、より効率的な計算で高い精度を提供します。
*   **Inception-ResNet-v2**:
    *   **特徴**: InceptionモジュールとResidual Connectionsを組み合わせた非常に深いネットワークで、高い精度を誇ります。
*   **ShuffleNet**:
    *   **特徴**: モバイルデバイス向けに設計された非常に効率的な畳み込みニューラル ネットワークです。
*   **NASNet-Mobile, NASNet-Large**:
    *   **特徴**: Neural Architecture Search (NAS) によって設計されたネットワークで、高い性能を発揮します。NASNet-Mobileはより軽量で、NASNet-Largeはより大規模です。モジュールの線形シーケンスで構成されていません。
*   **DarkNet-19, DarkNet-53**:
    *   **特徴**: YOLOオブジェクト検出器のバックボーンとして使用されることが多いネットワークです。
*   **EfficientNet-b0**:
    *   **特徴**: モデルのスケーリングに焦点を当てたネットワークで、効率性と精度を両立させています。
*   **AlexNet**:
    *   **特徴**: 初期の大規模なCNNの1つで、畳み込みニューラル ネットワークの転移学習の例でよく使用されます。

**2. オーディオ処理用事前学習済みネットワーク**
`audioPretrainedNetwork` 関数を使用して読み込むことができ、Audio Toolbox™ の機能を利用します。
*   **YAMNet**: 音声分類に使用されます。
*   **VGGish**: 音声データからの特徴埋め込み抽出に使用されます。
*   **OpenL3**: 音声データからの特徴埋め込み抽出に使用されます。
*   **CREPE**: ピッチ推定に使用されます。
*   **VADNet**: 音声区間検出 (VAD) に使用されます。

**3. オブジェクト検出用事前学習済みネットワーク**
Computer Vision Toolbox™ と連携して動作し、`yoloxObjectDetector` などのオブジェクト検出器モデルを介して利用されます。
*   **YOLO (v2, v3, v4)**:
    *   **特徴**: "You Only Look Once" の略で、イメージ内のオブジェクトをシングルショットで検出するための高速な検出器です。DarkNetなどのバックボーンネットワークを使用します。
*   **YOLOX**:
    *   **特徴**: YOLOシリーズの改善版で、検出性能と効率性を両立させています。
*   **RTMDet**:
    *   **特徴**: リアルタイム検出に最適化されたネットワークです。
*   **SSD (Single Shot MultiBox Detector)**:
    *   **特徴**: 複数のオブジェクトをシングルショットで検出するフィードフォワード畳み込みニューラル ネットワークです。ResNet-50などを特徴抽出ネットワークとして使用します。

**4. テキスト処理用事前学習済みモデル**
[MATLAB Deep Learning Model Hub](https://github.com/matlab-deep-learning/MATLAB-Deep-Learning-Model-Hub) GitHubリポジトリで提供されています。
*   **GPT-2, BERT, FinBERT**:
    *   **特徴**: テキストベースの変換器モデルで、テキスト分類、感情分析、その他のテキスト分析ワークフローに使用できます。
