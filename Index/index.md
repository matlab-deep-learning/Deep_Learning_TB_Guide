## 用語集

**MNIST**: 人が手で書いた0～9までの数字を大量に集めた画像データ集 (学習用60000枚、テスト用 10000枚用意されている)  

**ImageNet**: 画像認識評価用のデータセット 1400万枚以上のカラー画像を収録している  

**CIFAR-10**: 乗り物や動物など10クラスに分類されたカラー画像を数万枚収録している  

**Yamnet**: 音声波形を入力として受け取り、521種類の音声イベントに識別することができる学習済のネットワーク。音声識別モデルの転移学習用モデルとして扱うケースがある。MATLAB®では Audio Toolbox™で提供される。  

**教師あり学習**: 既知の入力に対して正解値を与えて、出力がその正解値になるように学習していく  

**教師なし学習**: 既知の入力に対して正解値を与えないで、その入力データそのものから分類分けするような学習  

**回帰学習**: 入力値から実数値を予測するためのモデルを学習する  

**分類学習**: 入力値からカテゴリ値を予測するためのモデルを学習する  

**セマンティックセグメンテーション**(Semantic Segmentation): 画像のピクセルごとにカテゴリ分類する深層学習レベル。MATLABでは、 Computer Vision Toolbox™で提供される。利用用途として、自動運転、医療画像処理などがあげられる。  

**インスタンスセグメンテーション**(Instance Segmentation): 画像のピクセルごとにカテゴリ分類する深層学習レベル。セマンティックセグメンテーションとは異なり、重なりのある別々の物体を別々に検出する点、特定物体以外は認識させない点などが挙げられる。MATLAB ではComputer Vision Toolboxで提供される。  

**Yolo**: 物体を検出するときに使用される代表的なアルゴリズムで You Only Look Once という英文の頭文字。「一度見るだけでよい」のように人間のように一目みるだけで物体検出ができることを指す。Yolo には幾つかのバージョンが存在する。MATLAB では Computer Vision Toolbox で提供される。  
 
**CNN**: 畳み込みニューラルネットワーク(Convolutional Neural Network)の略。中間層に畳み込み層のフィルタを利用してデータを変換していくことが大きな特徴(フィルタ出力がネットワーク内部的な特徴量となる)。全結合層と比較すると学習パラメータのサイズを小さくすることができる。  

**LSTM**(Long Short Term Memory): ニューラルネットワークの一つで、リカレントニューラルネットワークを改良したもの。主に時系列信号に対するモデルを設計する時の一手法となる。 Deep Learning Toolbox™ では、 lstmLayer() と呼ばれる層が提供される。  
 
**リカレントニューラルネットワーク**(RNN): 主に時系列データを目的としたニューラルネットワークアーキテクチャ。特徴としてある隠れ層において自分自身の層に帰還するネットワークとなる。MATLABではシンプルなRNN はlayrecnet()と呼ばれる関数で提供される。trainnet や trainNetwork に適用する層群としては提供していない。  
 
**オートエンコーダー** (自己符号化器: Auto Encoder): ニューラルネットワークの一つで入力したデータを出力側の教師データにも与え、その中間層の値を特徴量としたり、データを圧縮または符号化するために用いる。
Deep Learning Toolbox では、 trainAutoEncoder 関数が用意されている。また、trainnet 等に与える深層ネットワークで設計することも可能。  
 
**活性化関数**(Activation Function): あるニューロンから次のニューロンへの出力過程において、入力された数値を特定の方法で変換し、その結果を出力する関数のこと。代表的なものとして、 ReLU関数やシグモイド関数などが挙げられる  
 
**シグモイド関数**: 活性化関数のうちの一つ。ロガリズムシグモイド関数 f(s) = 1/(1+exp(-s)) と、タンジェントシグモイド関数 f(s) = tanh(s) の２通りがある。  
 
**ReLU関数**: 活性化関数のうちの一つ。f(s) = min(0,s) の形が一般的。  

**ハイパーパラメータ**: 人手で学習前に決定しておくパラメータの事を指す。機械学習などが学習過程において最適化されるパラメータではない。  
 
**推論**: 機械学習分野では、学習済のモデルに対して、モデルへ未知の入力を与えた時の出力結果を推論と呼ぶ。MATLABでは、 predict や classify といった関数で求めることが多い  
 
**損失**(Loss): 正解値とモデルによる出力された予測値とのズレの大きさ。損失関数には様々あるが、特に平均二乗誤差(MSE)が有名。他には平均絶対値誤差(MAE)、平均二乗誤差の平方根(RMSE)などが挙げられる。  

**学習率**: ニューラルネットワークの勾配降下法などで使われるハイパーパラメータの一つ。誤差面上の勾配を一度にどれだけ進むかを決める (w[n+1] = w[n] + η*⊿w[n]) 。 Deep Learning Toolboxでは、 InitialLearnRateFactor などでモデル全体の学習率を決定できる。各層にも相対的に学習率の大小を決定することができる( WeightLearnRateFactor や BiasLearnRatefactor など)  
 
**過学習**: 学習データに過剰に適合してしまったことにより、汎化性を失ってしまったことを指す。学習中に検証用データを定期的に用いて、検証データの誤差が連続的に上昇する時点で学習を抑制するのが一般的。  
 
**ドロップアウト**(Dropout): ニューラルネットワークの学習時に重みの一部を不活性化(0としてみなす)しながら学習することで、汎化性能を上げる手法の一つ。Deep Learning Toolboxでは、 dropoutLayer() で挿入することができる。  
 
**プーリング**(Pooling): 隠れ層(中間層)の出力である特徴マップのサイズを削減するための操作。
主に畳み込み層とペアで使われることが多く、特徴マップのサイズを縮小することで計算量を減らし、ネットワークのパラメータ数や計算負荷を削減することを目的とする。
最も一般的なプーリング操作としては、最大プーリング(Max Pooling) がある。特徴マップの各NxNの窓ごとの最大値のみを出力するような操作となります。
他には、平均プーリング(Average Pooling) などもある。  

**プルーニング** (剪定): ニューラルネットワークのパラメータ数を削減する手法の一つ
学習済のネットワークを用意し、ある閾値以下の重み要素を取り除きスパースなネットワークを作成する。 MATLABでは Deep Learnin Toolbox に taylorPrunableNetwork() で用意している  
 
**データ拡張**(Data Augmentation): 学習データが少ない場合にそのデータにランダムなリサイズや平行移動、回転、ノイズ負荷などを加えて学習するデータセットを増やすこと。Deep Learning Toolboxでは、ImageDatastore など入力データのデータストアに対して、 augmentedImageDatastore を使って、データ拡張用のデータストアに変換するのが一般的  
 
**転移学習**: 別のタスクで学習した学習済モデルのネットワークのパラメータを固定し、新たに追加した層の重みやバイアスのみを再学習すること。画像識別や音声識別などで有用であり、データが少ない際に有効な学習手法  

**データストア**: 深層学習において、一度にメモリに収まらないほど大きいデータ (ビッグ データ) の集合を処理し、表現するための便利な方法。
ネットワークの学習、検証、推論のために使用される。また、イメージ、シーケンス、オーディオ、テキストといった多様なデータ形式を扱うことができ、複数の入出力をもつネットワークの学習やデータの変換(transform)や統合(combine)することが可能。

**ミニバッチ**: 学習データ全体を何分割か小さなグループ単位に分割して推や誤差を計算、パラメータを更新させる方法。一度の計算に掛かる負荷を軽減しながら効率的に学習を進めていく。MATLABでは trainingOptionsで与えるオプションの一つとして MiniBatchSize がある。  

**エポック**: 学習データセット全体をニューラルネットワークに一度通して学習させる1サイクルのこと。例えば、画像のパターン数が 128 枚あった場合、その128個すべてを使い切ってモデルが1周学習すると1エポックとなる。  

**イタレーション** (繰り返し): 学習データセットをミニバッチに分割し、モデルのパラメータ(重みやバイアス) を1回更新するまでの一連の処理を指す。  
エポックとの関係性/違い: 
例えば、Minibatch のサイズが 32 の設定で、画像のパターン数が 128 枚あった場合、32枚毎画像をピックアップして重みが更新される。
全画像を用いて学習する為には、 4回の MiniBatch 処理が必要となる。
1回のMiniBatch 処理を 1 Iteration (重みが更新される回数) と呼び、全ての画像を使って学習した時点で 1 Epoch と呼ぶ。
上記例で 20Epoch の学習の場合、80回のイタレーションを要す。
 
**ONNX™**: Open Neural Network Exchange の略で機械学習モデル用に設計されたオープンソース形式のフォーマット。プラットフォーム間の互換性が確保され、主要な言語およびフレームワークもサポートされ、効率的なモデル交換ができる。オニキスと呼ぶ。Deep Learning Toolboxでは同フォーマットに対してインポート、エクスポート機能が用意されるが、サポートされない層もある。  
 
**混同行列**(Confusion Matrix): 分類モデルを性能を可視化するための表形式。  
行方向に実際のクラス、列方向に予測クラスとした行列の要素に各頻度(カウント数)を与える。MATLABでは、 confusionmat 関数で混同行列を求めることができる。
