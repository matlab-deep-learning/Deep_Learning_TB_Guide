ゼロからすべてを構築するのではなく、既に学習済みの強力なツールを活用するのが、最も速く深層学習を始める方法です。  
一般的に、学習済のネットワークを活用して深層学習を始める2種類の方法 (特徴抽出, 転移学習) があり、各々について解説します。

特徴抽出（Feature Extraction）と転移学習（Transfer Learning）は、いずれも事前学習済みの深層ニューラルネットワークを活用して新しいタスクに適用する手法ですが、そのアプローチと目的には重要な違いがあります。Toolboxで利用可能な学習済モデルについては、[次の章](../Pre_trained_network/index.md)で詳細について説明します。

以下に、それぞれの主な特徴と相違点をまとめます。

### 特徴抽出 (Feature Extraction)

特徴抽出は、**事前学習済みのネットワークが既に学習している強力で情報量の多い特徴表現を利用する**方法です。これは、深層学習を最も早く開始できる方法の一つとされています。

*   **アプローチ**: 事前学習済みのニューラルネットワーク（特に畳み込みニューラルネットワーク）から、中間層で学習された特徴を抽出します。これらの抽出された特徴は、サポートベクターマシン（SVM）のような**別のシンプルな分類器の入力として使用され、その分類器を学習させます**。
*   **利点**:
    *   **高速かつ簡単**: ニューラルネットワーク全体の学習に時間や手間をかけずに行えます。学習イメージを一巡する1つのパスのみが必要なため、GPUがない場合でも特に便利です。
    *   **過適合のリスク低減**: 非常に小規模なデータセットの場合、ニューラルネットワークの深い層を微調整しても精度が改善される可能性が低く、過適合のリスクも生じにくいため、特徴抽出が効果的です。
*   **適用シナリオ**:
    *   **データセットが非常に小さい場合**：特にクラスごとのイメージ数が約20未満のデータセットに推奨されます。
    *   **元のデータと新しいデータが非常によく似ている場合**: ネットワークの深い部分で抽出された具体的な特徴が新しいタスクに役立つ可能性が高いです。

[サンプルコード例](Feature_Extraction.md)  

### 転移学習 (Transfer Learning)

転移学習は、**事前学習済みのネットワークを新しいタスクの学習の開始点として使用し、そのネットワーク自体を新しいデータに合わせて微調整する**手法です。

*   **アプローチ**: 事前学習済みのネットワークを取得し、新しいタスクのデータセットでネットワークの層（通常は最終層や、より深い層）を再学習（微調整）します。これにより、ネットワークは新しいデータセットに固有の特徴を学習することができます。
*   **利点**:
    *   **効率的**: ゼロからネットワークを構築して学習させるよりも、はるかに簡単で時間がかかりません。
    *   **高い精度**: 多くの場合、最終的なネットワークの精度を最大限に高めることができます。これは、ネットワークが新しい特徴セットの抽出を学習できるためです。
    *   **既習知識の活用**: 事前学習済みのネットワークが既に多くの特徴を学習しているため、それらの特徴を他の類似タスクに適用できる利点があります。
*   **適用シナリオ**:
    *   **データセットが小規模から中規模の場合**: 数百個から数千個のラベル付けされたデータに適しています。
    *   **元のデータと新しいデータが類似している場合**: 特に効果を発揮します。データセットが非常に大規模な場合は、ゼロからの学習に比べて速度の利点がない可能性もあります。

### 特徴抽出と転移学習の比較

| 特徴              | 特徴抽出 (Feature Extraction)                       | 転移学習 (Transfer Learning)                            |
| :---------------- | :------------------------------------------------ | :------------------------------------------------------ |
| **定義**          | 事前学習済みネットワークから特徴を抽出し、別の分類器の学習に使用。 | 事前学習済みネットワークを新しいタスクの開始点とし、層を微調整して再学習。 |
| **主な目的**      | 迅速かつ簡単に深層学習の能力を活用。    | 高精度を追求し、新しいデータに特化した特徴を学習。 |
| **学習データ規模** | **非常に小さいデータセット**（クラスごとに約20イメージ未満の場合に推奨）。 | **小規模から中規模のデータセット**（数百～数千データ）。非常に大規模な場合はゼロからの学習と速度の差が小さい。 |
| **計算量・速度**  | **高速**（学習イメージの一巡パスのみ）。GPUがなくても可能。 | 特徴抽出より時間と手間がかかるが、ゼロからの学習より速い（数秒～数分）。GPUはオプションだが、速度向上のため推奨。 |
| **過適合リスク**  | 低い。                                        | 小規模なデータセットでは生じる可能性あり。      |
| **ネットワーク変更** | ネットワークは固定され、その出力特徴を使用。            | ネットワークの最終層などを新しいタスクに合わせて変更し、重みを再学習。 |
| **最終的な精度**  | 良い（事前学習モデルによる）。                 | **高い**（多くの場合、精度を最大限に高められる）。 |
| **データ類似性**  | 元のデータと**非常によく似ている**場合に深い特徴が効果的。 | 元のデータと**類似している**場合に効果的。        |
| **MATLABでの操作** | `imagePretrainedNetwork`で特徴を抽出し、`fitcsvm`などで学習。Deep Network Designerも利用可能。 | `imagePretrainedNetwork`でネットワークを読み込み、`trainnet`で再学習。Deep Network Designerでの対話的な操作も可能。 |

一般的に、新しいデータセットが**非常に小さい**場合や、**GPUなどの計算リソースが限られている**場合は、**特徴抽出**が迅速で効果的な選択肢となります。一方、**より高い精度を目指す**場合や、新しいデータセットの規模が**特徴抽出には小さすぎない**場合は、**転移学習（微調整）**がより優れた結果をもたらす可能性が高いです。
